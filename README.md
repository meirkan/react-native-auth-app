 Жобаның мақсаты
Мобильді қосымшаларға арналған заманауи, ыңғайлы және қауіпсіз пайдаланушыны сәйкестендіру (Authentication Flow) жүйесінің UI компоненттерін құрастыру.
Қолданылған технологиялар
 React Native — мобильді кросс-платформалы интерфейс құруға арналған кітапхана.  
 Expo — React Native жобасын жылдам дамыту және тестілеу құралы.  
 TypeScript — кодтың типтерін бақылау және қатесіз жазу үшін.  
 React Native Components (⁠SafeAreaView⁠, ⁠Pressable⁠, ⁠TextInput⁠, ⁠View⁠, ⁠Text⁠) — интерфейс элементтерін құрастыру үшін.  
Жоба құрылымы мен экрандар (Screens)
Жобада мынадай негізгі экрандар іске асырылған:  
1. ⁠LoginScreen.tsx⁠ — Қолданушының жүйеге кіру экраны.  
2. ⁠ForgetPassword.tsx⁠ — Құпия сөзді ұмытқан жағдайда телефон нөмірі немесе email арқылы қалпына келтіру экраны.  
3. ⁠verifyScreen.tsx⁠ — SMS арқылы келген растау кодын (OTP) енгізу экраны.
